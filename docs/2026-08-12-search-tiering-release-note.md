# 搜索:按来源分层排序 + 原始资料模式 + 转写稿收录

> 面向用户的发布说明,可直接贴进 GitHub Release 正文。
> 技术设计见 `docs/superpowers/specs/2026-08-12-source-globs-and-transcript-indexing-design.md`。

## 这次改了什么

搜索结果现在按**是谁写的**分组和排序:

| 分层 | 含义 | 排序权重 |
| --- | --- | --- |
| 你写的 | `.note.md` 手记、你签过字的、注册为笔记类的文档 | ×1.25 |
| AI 产出 | agent 生成的摘要、答复、论证 | ×1.0 |
| 原始资料 | 你**指定**的目录里的素材:电子书导出、字幕转写、博客原文 | ×0.9 |
| 未标注 | 既没有 frontmatter、也没命中你指定的模式 | **×0.3** |

「原始资料」不再靠猜。设置 → 搜索与索引 → **原始资料模式**里,你用通配模式
(`ebook/**`、`media/**/*.srt`)划出哪些目录是素材;粘一条 vault 内的路径,
它会给出从窄到宽的几条候选并实时显示各自命中多少文件。

## ⚠️ 升级后你会先看到什么:大量笔记被降权

**先说结论:升级后很可能有超过一半的文件落进「未标注」,在搜索里排得很靠后。**

在一个 8,971 个文件的真实 vault 上实测:

```
你写的  3,532      AI 产出  85      原始资料  5      未标注  5,349  (59.6%)
```

而且**把每一个转写目录都指定成原始资料,也只能把这个比例从 59.6% 降到 49.3%**
—— 因为绝大多数「未标注」文件不是素材,就是普通的、没写 frontmatter 的笔记。

×0.3 是**刻意的强降权**,不是估算失误。配合默认只取前 20 条结果,未标注的
文件很可能被挤出结果集。这么定是为了形成「不标注就搜不到」的压力,让你真正
在意的那批文档浮上来。我们知道这在上线第一天的观感就是「搜索变差了」,所以
把它写在这里,而不是让你自己撞上去。

### 出口有三个

1. **点开看看到底是哪些文件。** 设置 → 搜索与索引 → 来源分层里,「未标注」
   那一行是**可点的**,点一下就在搜索面板列出全部未标注文件。
2. **给文件补上任意 frontmatter。** 一个 `type:` 字段就够,那个文件会自己
   重新分层,**不需要重建索引**。如果它确实是原始资料,就把它加进上面的模式。
3. **不接受这个力度就改权重。** 同一页有四个权重输入框,把「未标注」调高即可,
   改完**下一次搜索立即生效**,同样不重建索引。

## 转写稿现在能被搜到了

`.srt` / `.vtt` / `.txt` 过去完全不在索引里 —— 体量最大的一批原始材料只能靠
`rg` 找。现在**只要落在你指定的原始资料模式内,它们就会被收录**:

- 字幕的序号行和时间码会被剔除(它们只会污染分词),但**行号仍然指向原文件的
  真实行**,`path#L123` 这个引用契约没有破。
- 连续字幕条会按目标字数合并成块,所以跨条的句子也能一次搜到。
- 大小写不敏感:`media/**/*.srt` 同样匹配 `B.SRT`。

体积代价实测:多收了 41.1 MB 正文,索引从 1.693 GB 增加 73.6 MB(**+4.35%**)。
转写稿的索引成本约为其自身字节数的 1.79 倍,远低于 markdown 的 10.6 倍。

## `origin:` 过滤器

应用内搜索和 `notemd search` 都支持:

```
origin:human       origin:derived      origin:source      origin:unlabeled
notemd search origin:unlabeled          # 列出所有该补 frontmatter 的文件
notemd search 会议纪要 origin:human
```

这套语法也写进了每个 vault 的 `AGENTS.md`,agent 可以直接用。

## 首次启动会重建一次索引

索引 schema 从 2 升到 3(多了「未标注」这一档,以及 `srt`/`vtt`/`txt` 三种
扩展名),旧库里存的分层结论全部作废,所以**升级后第一次打开会自动重建一次
索引**:

- 约十秒(9,000 个文件量级),重建期间搜索暂时不可用;
- **不丢任何数据** —— 索引是从你的 markdown 文件派生出来的一份可丢弃的副本,
  笔记本身一个字都不会动。

此后只有**改动原始资料模式**才会再触发重建;改权重不会。
