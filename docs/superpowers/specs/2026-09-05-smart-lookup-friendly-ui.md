# 智能查找交互调整

状态：已实现，完成交互审查。继承时间优先检索与 Smart Lookup 的单次 Planner 契约。

## 目标与边界

以 macOS 搜索窗口的习惯完成输入、等待、浏览、打开四个主要动作。快速简答和完整 Agent 仍由用户手动启动。保留已验证的时间约束和本地预览标记，不改变检索协议或增加自动模型调用。

## 界面与行为

- 搜索窗口初始为 1020×700、最小为 560×420；输入和设置操作不再自动改动窗口尺寸。搜索框使用系统字体、线性图标与清晰的焦点状态；提供清空和明确的查找按钮。运行中主按钮变成停止，停止后保留现有结果。空白输入展示两个可点击示例与键盘提示。
- 工作过程移到全宽状态区，实时显示最新状态；运行时展开可滚动日志，结束后可折叠查看。状态不得暴露凭证、原始 prompt 或 provider 自由文本。
- 结果与预览采用连续的双栏布局，降低重复边框和卡片。标题、日期、来源和命中摘要依次呈现；过滤后数量与实际列表一致。
- 结果单击预览、双击或 Enter 打开；上/下/Home/End 导航，Shift 扩展选择，Cmd/Ctrl+A 多选，Delete 仅从本次结果移除且可撤销。Cmd/Ctrl+F 聚焦搜索，IME 回车不触发查找。Tab 使用单一结果焦点入口。
- 原文预览显示已有命中块的有界文本与高亮，不只重复列表的一行；打开原文为主要动作，引用复制有即时反馈。
- 失败保留预览并提供重试；来源筛选为空提供恢复全部来源；隐藏全部结果提供撤销；真正零命中提供编辑问题或可用的扩大检索。不得提供无响应的按钮。
- 简答在有智能结果且功能启用时出现；完整 Agent 的入口保持次级。设置用有标题、完成按钮、点击外部关闭、Escape 与焦点管理的设置面板，分组显示理解/结果/简答，时间与预算归入高级选项。
- 简答启动时冻结来源、服务与预算；选择范围、来源筛选或相关设置变化会取消当前简答，使迟到响应失效。Agent 失败、超时和不完整响应使用稳定的本地化提示，展开工作日志也不展示服务返回的原始错误文本。
- 窄窗口提供结果/预览切换，避免两列最小宽度造成横向溢出。覆盖明暗外观、长标题、减少动画偏好和键盘焦点。
- 中文、英文、日文、德文文案同步；面向用户的界面去除 Planner、input-only、line 等内部术语。

## 验证

交互测试覆盖停止后迟到结果不覆盖、简答中改选取消、重试、方向键/多行输入/IME/焦点、清空、过滤后数量、复制反馈、设置关闭和错误文本边界。用真实组件配合本地宿主 mock 在浏览器检查空态、运行、结果、失败、设置、窄屏和深色外观；mock 仅用于测试。运行相关测试、类型检查与生产构建，独立审查后提交。
