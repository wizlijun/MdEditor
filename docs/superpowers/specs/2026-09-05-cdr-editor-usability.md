# CDR 编辑可用性补充契约

本文件补充 2026-09-04 唯一设计规格的 Stage 1B 编辑范围，取代“键盘结构推断 fail closed”的阶段性限制。实现保持通用 Editor Kit／Core，Memory 是首个 UI 消费者；不扩大 Claim 权限，不实现 Yjs、Publication 或完整 MEMORY MVP。

## 完成门槛

| 能力 | 必须证明的行为 |
| --- | --- |
| 连续输入 | Enter、Shift+Enter、中文输入、多段输入正常；保存等待期间仍能输入，不丢字、不回跳 |
| 选区与剪贴板 | 真实浏览器复制、剪切、纯文本/多段粘贴；跨块替换、全选清空后继续输入 |
| 常用编辑 | 正文/标题、内联格式、列表/缩进、引用、代码、链接、图片 URL、表格及行列增删、分隔线有可发现入口 |
| 身份和历史 | 普通改写保留 ID；插入新 ID、移动原 ID；结构撤销/重做和历史正文恢复生成合法新提交 |
| 保存 | 编辑立即标为未保存；仅 durable ack 可显示已保存；单一在途批次后续输入排队但不锁编辑器 |
| 失败 | 写失败保留完整候选稿、显示可复制/导出的内容；显式重试，不悄悄覆盖权威或丢稿 |
| 并发 | 同块 stale 不覆盖；IME 同块远端排队，异块可局部更新；ack 不覆盖请求发出后的输入 |
| 重开 | 成功提交后正文、块 ID 与业务修订可恢复；未完成的本地稿不冒充已保存 |

## 实现约束

1. OperationBatch 为有序原子变更，版本检查针对提交前版本，结构锚点针对依序变化的工作列表。跨块删除/替换不是多次可见提交。允许空正文，但提交后至少保留一个可编辑块。
2. 文档节点上的内部身份属性只在编辑器中使用，不进入 Markdown 正文；在输入事务进入历史前归一化。普通 HTML 剪贴板不能携带可伪造的治理身份。现存多节点语义块保持连续 span，新增空段拥有独立 ID，避免 Markdown 解析器吞掉空段。
3. 每个 surface 同时最多提交一个 batch。维护 committed snapshot、已发送候选和当前编辑稿三个明确状态。ack 对齐无本地后续修改的部分，不用整篇 setContent。后续稿基于 ack 形成下一批。
4. 失败恢复与提案降级分开：持久化失败停留在可导出的本地稿，停止自动重试；已存 proposal 恢复 committed 正文，保留建议提示及尚未提交的候选稿。无法自动处理的同块冲突进入显式比较，不重写 expected revision 来强制覆盖。
5. 恢复退役 ID 必须携带精确 `restoreFrom` 历史引用；历史正文恢复是新提交，不回退 head，不复活旧核验结论。现有 v2–v5 session 严格升级为 v6。
6. `contract.ts` 是 Host/插件共享的 type-only 契约。commands 只依赖实例 schema 和 ProseMirror 窄命令，Memory 不复制编辑逻辑。
7. 唯一的撤销栈仍是 ProseMirror history。历史记录使用按稳定块 ID 定位的 inverse，并对目标正文做精确前置检查；普通输入和其他插件继续使用原生 PM transaction。整组任一 inverse 冲突即拒绝整笔撤销，不消费半个历史事件；结构撤销遇到后续结构冲突时使用明确的历史正文恢复入口。键盘、工具栏与浏览器 beforeinput 共用受控撤销入口。
8. CDR 不安装会因光标进入链接/代码而改写正文的 live-preview 插件。格式维持真实 mark，通过工具栏修改；Editor Kit v1 的既有体验不变。
9. 失败稿的本机恢复副本明确不是 committed 数据。支持存储的 WebView 在重开时提示恢复，必须显式重试；stale 状态跨重开保留，不能转成可盲覆盖的普通保存失败。存储被禁用或超额时不承诺跨重开恢复，用户仍可复制/下载当前候选。
10. 插件在挂载前核对 `documentEditorApiVersion === 2`，旧宿主明确提示升级。该能力标志不代替正式发布的版本号/minimum host 门禁；发布时须配套升级 Host 与 Memory 插件。v6 写入后的 session 不支持旧插件原地降级读取。

## 验证方式

纯协议/恢复测试、真实 Moraya DOM 回归和独立 Chromium 键盘/系统剪贴板验收共同作为证据。浏览器自动化不等同于原生中文输入法或 macOS WKWebView 实机验收，报告中分别标记；不得将未执行的验收勾为通过。
