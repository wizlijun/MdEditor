# 自检(codex-agent)

确认这条链路真的通了：note.md → Codex CLI。

按顺序回答四件事,每件一两句话:

1. **你是哪个模型**(说型号,不要说"我是一个AI助手")。
2. **当前工作目录**是什么。
3. **你读到了哪些 `AGENTS.md`** —— 列出路径。这一条是重点:本目录一份,
   vault 根目录一份;两份都读到才算约定链路完整。
4. **写一个文件**:`output/selfcheck.md`,内容随意。报告成功了,还是收到了
   `[sandbox: file access denied …]`。两种结果都是有效的自检结论。

不要修改任何别的文件。不要联网。
